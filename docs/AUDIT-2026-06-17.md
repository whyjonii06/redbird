## Structure du monorepo

**5 zones** : `packages/` (core, api, plugin-sdk, cli), `plugins/` (8), `apps/` (5), `tests-integration/`, `docs/`

**Stack** : Node 22+, TypeScript strict, PostgreSQL 16, Drizzle ORM, tRPC v11, Next.js 15 / Vite + React Router, Tailwind v4, Vitest

---

## Ce qui est implémenté

### packages/core
Services : catalog (CRUD, variants, images, search ILIKE, tri, catégories M2M, i18n BCP47), cart (add/remove/merge/subtotal), orders (createFromCart, state machine pending→paid/fulfilled/cancelled/refunded, order numbers), customers (register/login scrypt), stock (reserve/release/commit/uncommit), promos (percentage/fixed, minAmount, maxUses, expiry), categories (tree hierarchy, parentId), reviews (CRUD, approval, rating stats), returns (approve/reject), staff (RBAC owner|admin|warehouse|support), CMS pages, abandoned cart recovery.

Schema : 10 migrations, 15+ tables (customers, products, product_variants, categories, stock_levels, carts, cart_line_items, orders, order_line_items, product_images, product_translations, product_reviews, return_requests, staff, promo_codes, product_attributes, attribute_values, variant_attribute_values, cms_pages).

Hook map : 20+ événements typés (product.*, variant.*, category.*, cart.*, order.*).

Registries : PaymentRegistry (duck-typing), EmailRegistry, PluginRegistry.

### packages/api
11 routers tRPC (~60 procédures) : catalog, categories, cart, checkout, customers, reviews, returns, cms, attributes, staff, admin.
Auth : JWT (publicProcedure / protectedProcedure / adminProcedure).
Webhook auto-discovery par path plugin.
Endpoints : /trpc/*, /webhooks/*, /setup/status, /meta.json.
Cron abandoned cart optionnel.

### packages/plugin-sdk
Types : PluginDefinition, PaymentIntent, PaymentProvider, EmailMessage, EmailProvider, WebhookHandler.
Templates email : orderConfirmation, orderPaid, orderFulfilled, orderCancelled.
Helpers : definePlugin(), definePluginConfig(), re-export Zod.

### packages/cli
`forge info` (statut DB), `forge seed` (6 produits café), `forge create` (scaffold partiel), `forge help`.

### plugins (8)
- **stripe** — PaymentIntents + HMAC webhook (tolerance 5min)
- **paypal** — Orders API v2 + OAuth2 + REST signature verification
- **shipping-flat** — zones multi-pays, freeOver threshold
- **vat-eu** — 27 pays EU, reverse charge B2B, validation VIES
- **reviews** — schema extension, cascade cleanup
- **email-resend** — templates transactionnels, dryRun
- **email-smtp** — skeleton
- **analytics** — hooks Plausible/GA4/console

### apps/backoffice (Vite + React Router, port 3000)
20 pages : Dashboard (KPIs + revenue chart 30j + orders by status), Orders, OrderDetail, Products, ProductForm (variants + stock + images URL + catégories + SEO + i18n), Customers, CustomerDetail, Promos, Returns, Reviews, Staff, Categories, CMS, Settings, Setup wizard.

### apps/storefront (Vite SPA, port 5173)
Pages : Home, Products, CategoryPage, ProductPage (variants/stock/wishlist/avis), Cart, **CheckoutPage** (Stripe Elements + PaymentElement intégrés, fallback sans paiement), OrderConfirm, InvoicePage, Search, Wishlist, Login, Register, Account, CmsPageView.
Contextes : AuthContext (JWT), CartContext, WishlistContext.

### apps/storefront-classic, storefront-editorial, storefront-b2b (Next.js 15)
Thèmes de référence — catalog + cart basiques, pas de checkout Stripe câblé.

### Tests
Suite intégration complète (tests-integration/) : addresses, categories, checkout, customers, email, guest-checkout, i18n, images, plugins, promos, stock.
Tests unitaires : money, hooks, server, webhooks, vat-eu, shipping-flat.

## Lecture

Fondations excellentes — architecture plugin-first type-safe, dette technique quasi nulle.
PrestaShop v9 = 15 ans de features accumulées.

**3 chantiers MVP les plus rentables :**
1. **VAT EU wired au checkout** — taxAmount auto-calculé + affichage
2. **Image file upload** — endpoint multipart + backoffice UI
3. **PDF invoices** — génération sur order.paid + endpoint GET /invoices/:orderId.pdf
